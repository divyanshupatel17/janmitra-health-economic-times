## 📄 Abstract
**JanMitra Health** is an AI-powered patient communication system designed for India's primary healthcare. It bridges the "last-mile" gap in healthcare delivery by converting Primary Health Center (PHC) visits into actionable, easy-to-understand care plans tailored to the patient's language and literacy level.

### Key Features
- **Multimodal Input**: Accepts prescription images (handwritten/printed) and voice notes (from doctors/ANMs).
- **AI Processing**: Uses GenAI to extract medicines, dosages, and advice, then generates a plain-language schedule (e.g., "Morning: Take 1 pill before food").
- **Multilingual Delivery**: Delivers care plans in the patient's local language via WhatsApp, SMS, Voice Call, or Print.
- **Safety**: Includes hallucination audits and a "No new drugs" policy for safety.

## 🛠️ Tech Stack
- **AI/GenAI**: Multilingual LLMs, OCR for Indian scripts, RAG Engine (ICMR/WHO guidelines).
- **Backend**: Python/Node.js (implied).
- **Deployment**: Targeted for Ayushman Arogya Mandirs and NCD Clinics.
